# 05: refactor(uniform-reports): Penataan KPI Cards, Filter Bar Compact & Tabel Detail Penjualan

**What to build:**
Merapikan modul Laporan & Rekap Seragam agar memiliki kontrol filter compact, indikator KPI yang terstruktur, search bar untuk memfilter data penjualan memanjang, serta pemisahan visual yang tegas antara rekapitulasi penjualan dan fungsi klaim ke cabang.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Control bar filter ditata ulang secara compact dengan grid yang seimbang dan responsif.
- [ ] Tersedia input pencarian (search) untuk memfilter baris data penjualan saat hasil laporan memanjang ke bawah.
- [ ] Kartu ringkasan KPI (Order, Murid unik, Qty, Omzet) konsisten dengan standar visual Gudang Buku.
- [ ] Rincian penjualan per sekolah/jenjang disajikan dalam format tabel terstruktur.
- [ ] Panel "Klaim ke Cabang" memiliki wadah visual terpisah dengan riwayat klaim yang rapi dan indikator status/drift yang jelas.
