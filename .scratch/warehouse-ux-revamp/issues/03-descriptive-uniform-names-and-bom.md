# 03: Penamaan Deskriptif Seragam & Transparansi BOM pada Rakit Paket Seragam

**What to build:**
1. Katalog, form PO konveksi, dan seeder menyajikan nama deskriptif lengkap per jenjang & gender untuk Paket Seragam (misal: Paket Seragam Lengkap SD Putra (Kain Harian + Kaos Olahraga)) dan Item Satuan Seragam (misal: Kain Bahan Seragam Harian SD Putra, Kaos Olahraga SD Putra (L)).
2. Pada tampilan perakitan paket seragam, pengguna dapat melihat panel rincian isi paket (BOM: nama item, ukuran, kuantitas per paket) dan ketersediaan stok bahan sebelum melakukan aksi rakit paket.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Kode paket seragam dan item seragam disajikan berdampingan dengan nama deskriptif lengkap
- [ ] Panel rincian isi paket (BOM) ditampilkan saat memilih paket seragam di form/tampilan rakit paket
- [ ] Stok bahan per komponen BOM ditampilkan untuk memandu jumlah yang dapat dirakit
